# Vue 靜態購物網站範例

本專案是一個以 Vue 3（CDN 模組方式）打造的靜態購物網站雛形，資料皆為寫死的展示內容，對應到管理員系統、會員系統與商品頁面等流程。

## 使用方式
1. 直接在瀏覽器開啟 `index.html` 即可檢視範例頁面。
2. 無需安裝任何套件或建置步驟，CSS 與 Vue 皆透過本地檔案與 CDN 載入。

## 內容重點
- **架構樹狀圖**：根據需求圖展示管理員、會員與商品頁面的主要流程節點。
- **分類卡片**：以卡片呈現不同系統的描述、功能與負責團隊。
- **會員標籤**：展示會員任務與等級標籤的靜態資料。
- **商品卡片**：三個示意商品，含價格、標籤與操作按鈕。
